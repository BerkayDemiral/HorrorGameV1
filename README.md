# 🕯️ HorrorGame v1

> A Unity-based prototype horror game project. Initially started as a horror experience, it has gradually evolved into a gameplay systems and mechanics-focused development environment.

---

## 🚧 Development Status

Main goals of the project:
- Deliver an interactive and atmospheric horror experience.
- Build reusable gameplay systems (inventory, UI, lighting, map, etc.).

Currently, the focus is primarily on **gameplay mechanics, system development**. Thematic content and level design will be added in future updates.

---

## 🛠️ Implemented Features

### 🎮 Player and Interaction Systems
- FPS camera and character setup
- Ladder climbing mechanics
- Flashlight, lighter, and candle interactions (light system)
- Door interactions with locked/unlocked mechanics (key-based unlocking)
- Chest system (locked & lootable)

### 💡 Lighting and Atmosphere Systems
- Flashlight and light toggling system
- Flickering light effect
- Sound-integrated light interaction

### 📦 Inventory & UI Systems
- Compass synced with player rotation
- Minimap displaying player and items
- Interactable object descriptions (UI display)
- Quick access item slots
- HUD: Health, stamina, item indicators

### ⚙️ Additional Mechanics
- Random object spawn system
- Random loot drops from locked chests
- FPS object sway effect (on held items, based on mouse movement)

---

## 📁 Setup and Running the Project

1. Open the project with Unity 2022 or newer
2. Load the scene at `Assets/Scenes/MainScene.unity`
3. Press the play button to test the game
